SportsAPI Archive privacy policy

Last updated: 27 September 2026.

SportsAPI Archive is a personal backup tool used only by its owner. It uses Google OAuth so rclone can access the owner's Google Drive account for a dedicated encrypted restic backup repository.

Google Drive data and permission

The requested full Drive permission can technically see, create, edit and delete all files in the authorized Drive account. The tool's configuration directs operations to its recovery repository, but this configuration does not narrow the OAuth permission. Backup, verification, restore and repository-maintenance operations may process Drive file names, metadata and encrypted repository objects.

Storage and sharing

Restic encrypts backup contents before rclone transfers them to Google Drive. The tool has no advertising, public user accounts or sharing feature; it does not sell Drive data. Encrypted backup objects are stored with Google Drive as the chosen storage provider. OAuth credentials are held in the owner's private configuration, not on these information pages.

These static pages are hosted by GitHub Pages and have no Google sign-in or data-entry form. The owner controls backup repository maintenance and deletion; no fixed retention period is promised. Revoking OAuth access stops future authorized Drive operations but does not itself delete already stored backup objects or local copies.

Control of access

The owner can review or remove this app's access in Google Account connected-app settings. See Google's instructions for managing linked apps. Removing access prevents future Drive operations until the owner authorizes the tool again.
