SportsAPI Archive

SportsAPI Archive is a personal tool for the owner's server recovery backups. It is not a public account or file-sharing service.

The tool uses restic to encrypt backup data before rclone transfers repository objects to the owner's Google Drive. Its configuration directs backup operations to a dedicated recovery repository.

Rclone requests full Google Drive access. That permission can technically view, create, change and delete files throughout the authorized Drive account. The configured repository is an operational choice, not a restriction on the OAuth permission.

Only the owner uses this tool. It has no advertising, public users or sharing feature. This page does not ask for Google credentials.
